# 自动驾驶感知评价指标说明

## TP 定义

TP，全称 True Positive，表示真实存在的目标被系统正确检测出来。

在自动驾驶感知评价中，如果一个真实目标和一个检测目标在空间位置、类别和时间戳上满足匹配规则，则该检测结果可以被统计为 TP。

## FP 定义

FP，全称 False Positive，表示系统检测出了一个实际不存在的目标。

在感知评价中，FP 通常表示误检。例如道路上没有行人，但系统输出了一个行人目标，则该目标可能被统计为 FP。

## FN 定义

FN，全称 False Negative，表示真实存在的目标没有被系统检测出来。

在自动驾驶感知评价中，FN 通常表示漏检。例如前方存在车辆，但感知系统没有输出对应目标，则该真实目标可能被统计为 FN。

## Precision 和 Recall

Precision 表示检测结果中有多少是正确的，计算公式为：

Precision = TP / (TP + FP)

Recall 表示真实目标中有多少被成功检测出来，计算公式为：

Recall = TP / (TP + FN)
